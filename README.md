# Guides for TurtleBot3 Setup & Usage

The following subdirectories detail specific aspects of usage.

- [Simulation Environment](sim/) (ROS 2 Jazzy and Gazebo Sim Harmonic, running in the AICE2011 lab container)

- [Object Design](object/) (CAD for the objects used as part of the AICE2011 module @ University of Southampton)

- See the [TB3 guides](docs/) for information on setting up and using the TurtleBot3 (including creating a custom image, Fast DDS over Tailscale, and setting up the camera). **These files are likely to change, so make sure you are viewing the latest version.**

- The lab environment itself is provided by the [AICE2011 container](https://github.com/tgodfrey0/AICE2011_Container).
